Every file, stream and disc. Built from scratch.

How it works

One pipeline, every source.

Bytes come in from a file, a stream or a disc; rexplayer works out what they are from the bytes themselves, never the file name, and plays them in time.

01

Recognise

Every format reader scores the first bytes of the file. The best match opens it, so a renamed file still plays.

02

Decode

rexplayer's own decoders handle the open formats. Patented ones go to the decoders Windows already licenses, so nothing is reinvented that should not be.

03

Play in time

The audio device's own clock leads. Seeks land on the exact sample, and a new seek interrupts the old one immediately.

What is inside

Small parts, each proved.

Its own decoders

MP3, FLAC, WAV and AIFF, decoded by rexplayer itself and checked against independent decoders, with tags and cover art read from ID3 and Vorbis comments.

The player window

A playlist, full screen, snapshots, preferences and every shortcut in the menus, with one window for everything you open.

Video on the graphics card

MP4, MOV, MKV and WebM, with H.264, HEVC and AAC decoded by Windows on the graphics card when it can, drawn with Direct3D and kept in step with the sound.

Its own resampler

A windowed-sinc resampler converts to whatever rate your audio device mixes at, without drifting over hours.

Gapless

Albums play from one track to the next without a gap, and MP3 encoder padding is cut to the sample.

Windows audio

Plays to the default device through WASAPI, with volume up to 200 % and a soft clipper above 100 %.

A command line for scripts

rexplay prints exactly one JSON document per command when asked, so tools and agents can drive it reliably.

Tested to the line

Every line of the engine runs in tests on each change, including exact-sample checks of what was played.

Get it

Install it for yourself.

  1. Download the installer from the latest release. It installs for you only, with no administrator prompt.
  2. The installer is not signed yet, so Windows may say "Windows protected your PC". Choose More info, then Run anyway.
  3. Open a terminal and play something:
    rexplay play song.wav

Prefer no installer? Each release also has a portable zip with a SHA-256 file to check it against.

Questions

Fair questions.

Why build a media player from scratch?

Because the parts that matter, timing, seeking, the audio path and what happens with a damaged file, should be understood and tested end to end by the people who ship them.

Does it send anything anywhere?

No telemetry, no account, no analytics. It touches the network only when you open something on the network.

Will it play my videos?

MP4, MOV, MKV and WebM files with H.264 or HEVC video play in the rexplayer window, decoded on your graphics card when it can. Drop a file on the window, or open it from Explorer.

Can scripts and agents use it?

Yes. Add --json to any command, or run rexplay agent capabilities, and it prints exactly one JSON document.
